# posts

여기에 `.md` 파일을 추가해 main에 올리면 GitHub Actions가 Discussion 글로 자동 게시합니다.

파일 이름: `YYYY-MM-DD-scrum.md`, `YYYY-MM-DD-sprint.md`

파일 맨 위 형식:

```
title: [스크럼] 1주차 2일차 11/2(월)
category: Scrum
---
## 공통
...
```

- `category`는 Discussions 카테고리 이름 그대로 (`Scrum`, `Sprint`)
- 이미 있는 파일을 고쳐도 다시 게시되지 않습니다 (새 파일만 게시)
